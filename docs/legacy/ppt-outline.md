# PPT 大纲

1. 赛题背景与目标
   - 景区游客需要低门槛、可信、连续的导览服务
   - 景区管理方需要可维护知识库、反馈分析和运营数据

2. 用户与场景
   - 普通游客：问景点、听讲解、规划路线、收藏内容
   - 景区运营人员：维护景点和知识库，查看反馈和行为数据
   - 评委演示场景：无付费 Key 也能跑通核心链路

3. 总体方案
   - Vue 3 前端提供游客端、数字人页和后台
   - FastAPI 后端提供问答、RAG、路线、语音、反馈、行为和大屏接口
   - PostgreSQL 存业务数据，Chroma 存向量索引

4. 数据与知识库
   - 官方灵山胜境结构化资料导入
   - 文档上传、解析、清洗、切分、景点关联
   - 向量检索优先，关键词检索兜底

5. 智能问答链路
   - 用户问题进入 RAG 检索
   - Prompt 限定景区导游身份和拒答边界
   - DeepSeek/Qwen 可接入，无 Key 时本地降级

6. 数字人与语音
   - ASR 接口兼容 faster-whisper
   - TTS 协议支持云端，默认浏览器 TTS 降级
   - 2D 数字人页面承载讲解、字幕和语音播放

7. 个性化路线
   - 输入兴趣、时长、同行人群
   - 输出景点顺序、停留时长和推荐理由
   - 支持路线与景点收藏

8. 管理后台
   - 知识库管理
   - 景点管理
   - 行为数据 CSV 导入
   - 游客反馈与满意度分析

9. 数据大屏
   - 会话数、消息数、景点数、知识块数
   - 反馈情绪、收藏类型、行为事件分布
   - 平均满意度、响应延迟、停留时长

10. 测试与部署
   - `scripts/smoke_test.py` 验证核心接口
   - `data/eval/qa_testset.json` 提供 100 条问答评测集
   - Docker Compose 一键启动，后端自动迁移

11. 创新点
   - 面向景区的可控 RAG 问答
   - 无付费 Key 的完整演示降级链路
   - 游客体验和运营分析同时闭环

12. 总结
   - MVP 已覆盖游客服务、管理维护、数据分析和部署验证
   - 后续可增强实时数字人口型、地图导航和更多景区数据源
